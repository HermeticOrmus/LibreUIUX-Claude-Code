# Competitor map: LibreUIUX-Claude-Code

## How this fills

1. Name the product and its surfaces (plugins, agents, skills, commands, install paths).
2. WebSearch / WebFetch public competitor docs, READMEs and homepages: other Claude Code plugin packs and marketplaces in this domain, Cursor rules and plugins, Codex or Gemini CLI extensions, and standalone tools people use for the same job.
3. One row per competitor; blank unknowns; cite a URL per row.
4. Fill the capabilities matrix (Y / N / P / ?) with the capabilities that matter in this domain, and a source per claimed cell.
5. Save as `YYYY-MM-DD-competitor-map.md` (keep this template).

Star counts are `stargazers_count` from the GitHub REST API, read on 2026-09-30. Feature claims come from each project's README or homepage as fetched on 2026-09-30.

## Product

- Name: LibreUIUX Claude Code, v2.0.0 on main.
- Flagship: the `libreuiux` marketplace, 71 installable plugins. 5 are original (design-mastery, archetypal-alchemy, mcp-integrations, vibe-coding, libreuiux-hooks); 66 derive from [wshobson/agents](https://github.com/wshobson/agents) (MIT, Seth Hobson), per `NOTICE.md` and `.claude-plugin/marketplace.json`.
- Our surfaces:
  - Plugins installed as `<plugin>@libreuiux` (`/plugin marketplace add HermeticOrmus/LibreUIUX-Claude-Code`), or all at once with `./setup.sh`. The README counts 152 agent definitions (93 distinct), 76 command files (65 distinct), 74 skills, 3 hooks.
  - UI/UX plugins: `design-mastery` (3 agents, 4 commands incl. `/design-audit` and `/style-guide`, 5 skills, an eval suite in `plugins/design-mastery/evals/`), `accessibility-compliance` 1.2.0 (agent `ui-visual-validator`, command `/accessibility-audit`, no skills), `frontend-mobile-development`, `archetypal-alchemy`, `mcp-integrations` (skill `browser-devtools-mcp`, guidance only, no MCP server config), `vibe-coding`, `libreuiux-hooks` (post-edit pattern checks for accessibility and design-system impact).
  - Learning paths in `beginner/`, `intermediate/`, `advanced/`, and CLAUDE.md templates in `templates/`.
  - Root `.claude/commands/` (`ui-modern`, `ui-critique`, `ui-responsive`, `ui-review`, `ui-synth`) and `.claude/agents/synthesis-master.md`: copied by hand (README "Path 3"), not part of any plugin.
  - Known gaps on main: README links four folders that do not exist (`advanced/mcp-servers/chrome-devtools/`, `advanced/slash-commands/`, `intermediate/examples/saas-dashboard/`, `intermediate/examples/ecommerce-product/`). A relative-link scan of the Markdown docs on 2026-09-30 counted links to missing targets (repeats included): `README.md` 4, `QUICK_START.md` 3, `advanced/README.md` 15, `intermediate/README.md` 23, `beginner/README.md` 2, `TROUBLESHOOTING.md` 1.
